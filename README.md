# Orialis Mail : versions publiées

Ce dépôt ne contient que les fichiers compilés d'Orialis Mail, un copilote IA pour Thunderbird. Le code source est privé.

- `updates.json` : lu chaque jour par Thunderbird pour mettre l'extension à jour.
- `latest.json` : lu par Orialis Mail pour proposer la mise à jour du relais local.
- Les fichiers sont joints à chaque [release](https://github.com/Djouz83/orialis-mail-releases/releases), avec leur empreinte SHA-256.
